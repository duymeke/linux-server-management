# Linux Server Management

## Project Purpose

This project demonstrates professional Linux server management using Bash scripts and a professional Git workflow.

## Project Structure

- scripts/ - Linux administration scripts
- docs/ - project documentation
- README.md - project overview
- .gitignore - Git configuration

## Development Workflow

New functionality is developed in separate branches.

After development, changes are submitted through Pull Requests and reviewed before merging.

## Branching Strategy

The main branch contains stable versions of the project.

Feature branches are used for new functionality.

Example:

feature/system-info
feature/backup
feature/documentation

## Contribution Process

1. Create a feature branch.
2. Develop the feature.
3. Commit the changes.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. Participate in code review.
7. Resolve review comments.
8. Merge the Pull Request.

## Testing Process

Scripts are executed locally to verify that they work correctly.

## Troubleshooting Process

Problems are investigated using Git history, script output, and system information.

## Testing Examples

Run:

./scripts/system_info.sh

./scripts/backup.sh
